# 租房管理系统

## 项目结构

- **lease/**: 后端项目
- **rentHouseApp/**: 移动端前端项目
- **rentHouseWeb/**: 网页端前端项目

## 技术栈

### 后端
- Java Spring Boot
- MyBatis-Plus
- MySQL
- Swagger

### 前端
- Vue 3
- Vite
- Element Plus
- Pinia

## 快速开始

### 后端启动
1. 进入 `lease` 目录
2. 执行 `mvn spring-boot:run`

### 前端启动
1. 进入对应前端目录
2. 执行 `npm install` 安装依赖
3. 执行 `npm run dev` 启动开发服务器

## 接口文档

后端接口文档可通过访问 `http://localhost:8081/swagger-ui.html` 查看。
