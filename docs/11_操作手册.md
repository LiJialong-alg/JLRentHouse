## 1. 手册简介

### 1.1 手册目的

本手册旨在帮助管理员和运营人员熟练掌握公寓租赁管理系统（Admin管理端）的各项操作，确保系统正常运行和维护。

### 1.2 适用范围

本手册适用于：
- 系统管理员
- 运营管理人员
- 客服人员

### 1.3 系统简介

公寓租赁管理系统（Admin管理端）是面向企业内部管理人员的后台系统，提供公寓管理、房间管理、预约管理、租约管理等功能。

## 2. 系统登录

### 2.1 登录操作

**操作步骤：**
1. 打开浏览器，输入系统地址
2. 进入登录页面
3. 输入用户名和密码
4. 点击"登录"按钮
5. 登录成功进入系统首页

**默认账号：**
| 角色 | 用户名 | 密码 |
|-----|-------|------|
| 超级管理员 | admin | admin123 |

### 2.2 退出登录

**操作步骤：**
1. 点击右上角用户名
2. 点击"退出登录"
3. 确认退出
4. 跳转到登录页面

## 4. 系统管理

### 4.1 用户管理

#### 4.1.1 查询用户

**操作步骤：**
1. 进入"系统管理 > 用户管理"
2. 输入查询条件（用户名、姓名、手机号）
3. 点击"查询"按钮
4. 查看用户列表

#### 4.1.2 新增用户

**操作步骤：**
1. 进入"系统管理 > 用户管理"
2. 点击"新增"按钮
3. 填写用户信息：
   - 用户名：必填，唯一
   - 姓名：必填
   - 手机号：选填
   - 岗位：必填，选择岗位
   - 状态：必填，正常/禁用
4. 点击"保存"按钮
5. 新增成功提示

#### 4.1.3 编辑用户

**操作步骤：**
1. 在用户列表中找到目标用户
2. 点击"编辑"按钮
3. 修改用户信息
4. 点击"保存"按钮
5. 更新成功提示

#### 4.1.4 删除用户

**操作步骤：**
1. 在用户列表中找到目标用户
2. 点击"删除"按钮
3. 确认删除操作
4. 删除成功提示

**注意事项：**
- 系统管理员不可删除
- 删除前请确认无关联业务

### 4.2 岗位管理

#### 4.2.1 查询岗位

**操作步骤：**
1. 进入"系统管理 > 岗位管理"
2. 输入查询条件（岗位名称、岗位编码）
3. 点击"查询"按钮
4. 查看岗位列表

#### 4.2.2 新增岗位

**操作步骤：**
1. 进入"系统管理 > 岗位管理"
2. 点击"新增"按钮
3. 填写岗位信息：
   - 岗位名称：必填
   - 岗位编码：必填，唯一
   - 状态：必填，正常/禁用
4. 点击"保存"按钮
5. 新增成功提示

## 5. 公寓管理

### 5.1 查询公寓

**操作步骤：**
1. 进入"公寓管理 > 公寓管理"
2. 选择区域（省、市、区）
3. 输入公寓名称
4. 选择发布状态
5. 点击"查询"按钮
6. 查看公寓列表

### 5.2 新增公寓

**操作步骤：**
1. 进入"公寓管理 > 公寓管理"
2. 点击"新增"按钮
3. 填写公寓信息：
   - 公寓名称：必填
   - 所属区域：必填，选择省市区
   - 详细地址：必填
   - 联系电话：必填
   - 公寓介绍：选填
4. 选择配套设施（可多选）
5. 选择公寓标签（可多选）
6. 上传公寓图片（最多9张）
7. 点击"保存"按钮
8. 新增成功提示

### 5.3 编辑公寓

**操作步骤：**
1. 在公寓列表中找到目标公寓
2. 点击"编辑"按钮
3. 修改公寓信息
4. 点击"保存"按钮
5. 更新成功提示

### 5.4 删除公寓

**操作步骤：**
1. 在公寓列表中找到目标公寓
2. 点击"删除"按钮
3. 确认删除操作
4. 删除成功提示

**注意事项：**
- 删除前请确认无关联房间
- 删除后关联数据一并清除

### 5.5 发布/下架公寓

**操作步骤：**
1. 在公寓列表中找到目标公寓
2. 点击"发布"或"下架"按钮
3. 确认操作
4. 状态更新成功

## 6. 房间管理

### 6.1 查询房间

**操作步骤：**
1. 进入"公寓管理 > 房间管理"
2. 选择所属公寓
3. 输入房间号
4. 选择发布状态
5. 选择入住状态
6. 点击"查询"按钮
7. 查看房间列表

### 6.2 新增房间

**操作步骤：**
1. 进入"公寓管理 > 房间管理"
2. 点击"新增"按钮
3. 选择所属公寓
4. 填写房间信息：
   - 房间号：必填
   - 月租价格：必填，元/月
5. 选择配套设施（可多选）
6. 选择房间标签（可多选）
7. 选择租期（可多选）
8. 选择支付方式（可多选）
9. 点击"保存"按钮
10. 新增成功提示

### 6.3 编辑房间

**操作步骤：**
1. 在房间列表中找到目标房间
2. 点击"编辑"按钮
3. 修改房间信息
4. 点击"保存"按钮
5. 更新成功提示

### 6.4 删除房间

**操作步骤：**
1. 在房间列表中找到目标房间
2. 点击"删除"按钮
3. 确认删除操作
4. 删除成功提示

**注意事项：**
- 已入住的房间不可删除
- 删除前请确认无关联租约

---

## 7. 预约看房管理

### 7.1 查询预约

**操作步骤：**
1. 进入"租赁管理 > 预约看房"
2. 选择预约状态
3. 输入手机号
4. 选择预约时间范围
5. 点击"查询"按钮
6. 查看预约列表

### 7.2 更新预约状态

**操作步骤：**
1. 在预约列表中找到目标预约
2. 点击"操作"栏下拉按钮
3. 选择新状态（已看房/已取消/已过期）
4. 确认操作
5. 状态更新成功

### 7.3 删除预约

**操作步骤：**
1. 在预约列表中找到目标预约
2. 点击"删除"按钮
3. 确认删除操作
4. 删除成功提示

**注意事项：**
- 已过期的预约建议定期清理
- 删除后数据无法恢复

## 8. 租约管理

### 8.1 查询租约

**操作步骤：**
1. 进入"租赁管理 > 租约管理"
2. 选择租约状态
3. 输入手机号
4. 选择租约日期范围
5. 点击"查询"按钮
6. 查看租约列表

### 8.2 新增租约

**操作步骤：**
1. 进入"租赁管理 > 租约管理"
2. 点击"新增"按钮
3. 填写租约信息：
   - 承租人姓名：必填
   - 承租人手机号：必填
   - 承租人身份证号：选填
   - 签约公寓：必填
   - 签约房间：必填
   - 租期开始日期：必填
   - 租期结束日期：必填
   - 租期：必填
   - 月租金：必填
   - 押金：选填
   - 支付方式：必填
   - 备注：选填
4. 点击"保存"按钮
5. 新增成功提示

### 8.3 取消租约

**操作步骤：**
1. 在租约列表中找到目标租约
2. 点击"取消"按钮
3. 确认取消操作
4. 租约状态变更为"已取消"

### 8.4 确认退租

**操作步骤：**
1. 在租约列表中找到状态为"退租待确认"的租约
2. 点击"确认退租"按钮
3. 确认操作
4. 租约状态变更为"已退租"
5. 房间状态更新为"未入住"

### 8.5 续约

**操作步骤：**
1. 在租约列表中找到目标租约
2. 点击"续约"按钮
3. 填写续约信息：
   - 新租期开始日期
   - 新租期结束日期
   - 新月租金
4. 点击"确定"按钮
5. 续约成功，新租约生成

## 11. 常见问题处理

### 11.1 登录问题

**Q: 登录提示"用户不存在"**
A: 检查用户名是否正确，或联系管理员创建账号。

**Q: 登录提示"密码错误"**
A: 检查密码是否正确，区分大小写。

**Q: 登录提示"账号已被禁用"**
A: 联系管理员启用账号。

### 11.2 操作问题

**Q: 保存数据失败**
A: 检查必填项是否填写完整，或网络是否正常。

**Q: 删除数据失败**
A: 检查是否有下级关联数据，需先删除关联数据。

**Q: 图片上传失败**
A: 检查图片格式和大小是否符合要求。

### 11.3 系统问题

**Q: 页面打不开**
A: 尝试刷新页面或清除浏览器缓存。

**Q: 数据显示不完整**
A: 尝试翻页或调整筛选条件。
