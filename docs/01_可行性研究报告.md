---

**项目名称：** 公寓租赁管理系统

## 1. 引言

### 1.1 背景

随着城市化进程的加快和人口流动性的增加，公寓租赁市场需求日益旺盛。传统的公寓租赁管理方式主要依靠人工记录和纸质文档，存在效率低下、信息查找困难、数据容易丢失等问题。为了提高公寓租赁管理的效率和质量，开发一套功能完善、操作简便的公寓租赁管理系统具有重要的现实意义。

本项目旨在开发一套面向公寓租赁企业的管理系统，实现公寓信息管理、房间管理、看房预约管理、租约管理、用户管理等功能，提高工作效率，减少人为错误，提升服务质量。

### 1.2 目的

本可行性研究报告的目的是对公寓租赁管理系统的开发进行全面的技术、经济和操作可行性分析，为项目决策提供科学依据。

### 1.3 范围

本报告涵盖以下方面的可行性分析：
- 技术可行性
- 经济可行性
- 操作可行性
- 社会可行性

## 2. 系统概述

### 2.1 系统目标

本系统旨在为公寓租赁企业提供一个集成化的管理平台，实现以下目标：

1. **信息管理规范化**：建立标准化的公寓和房间信息管理流程，确保数据的准确性和完整性。

2. **业务流程自动化**：通过系统自动化处理看房预约、租约签订等业务流程，减少人工干预，提高效率。

3. **决策支持数据化**：通过数据统计和分析，为管理者提供决策支持。

4. **服务质量提升**：为租客提供便捷的预约看房服务，提升用户体验。

### 2.2 系统结构

系统采用B/S架构，包含以下主要模块：

| 模块名称     | 功能描述                                 |
| ------------ | ---------------------------------------- |
| 公寓管理模块 | 公寓信息录入、编辑、发布管理             |
| 房间管理模块 | 房间信息管理、房间状态跟踪               |
| 属性管理模块 | 配套设施、标签、杂费、租期、支付方式管理 |
| 看房预约模块 | 预约看房申请处理、预约状态管理           |
| 租约管理模块 | 租约签订、续约、退租等全流程管理         |
| 系统管理模块 | 用户管理、岗位管理、角色权限管理         |
| 用户管理模块 | 租客信息管理                             |

### 2.3 技术架构

**前端技术栈：**
- Vue 3：渐进式JavaScript框架
- Element Plus：UI组件库
- Vite：构建工具
- TypeScript：类型安全
- SCSS：样式预处理
- Axios：HTTP请求库
- Pinia：状态管理
- Vue Router：路由管理

**后端技术栈：**
- Spring Boot 2.7：应用框架
- MyBatis-Plus：ORM框架
- Spring Data Redis：缓存支持
- MinIO：对象存储（图片管理）
- MySQL 8.0：关系型数据库
- JWT：身份认证
- Swagger/OpenAPI 3：接口文档

**基础设施：**
- JDK 1.8+
- Node.js 16+
- Maven 3.6+
