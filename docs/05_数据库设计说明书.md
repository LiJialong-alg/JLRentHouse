```yaml
spring:

      connection-test-query: SELECT 1

      idle-timeout: 500000
      max-lifetime: 540000
      maximum-pool-size: 12
      minimum-idle: 10
      pool-name: SPHHikariPool
```

### 2.2 连接池参数

| 参数 | 值 | 说明 |
|-----|---|------|
| maximum-pool-size | 12 | 最大连接数 |
| minimum-idle | 10 | 最小空闲连接 |
| connection-timeout | 60000 | 连接超时（毫秒） |
| idle-timeout | 500000 | 空闲超时（毫秒） |
| max-lifetime | 540000 | 最大生命周期（毫秒） |

## 3. 命名规范

### 3.1 表命名规范

| 规范 | 说明 | 示例 |
|-----|------|------|
| 统一小写 | 所有表名使用小写 | system_user |
| 使用下划线 | 单词间用下划线分隔 | apartment_info |
| 添加前缀 | 业务相关表加业务前缀 | lease_agreement |

### 3.2 字段命名规范

| 规范 | 说明 | 示例 |
|-----|------|------|
| 统一小写 | 所有字段名使用小写 | user_name |
| 使用下划线 | 单词间用下划线分隔 | create_time |
| 主键命名 | 主键统一命名为id | id |
| 外键命名 | 外键命名为{表名}_id | apartment_id |

### 3.3 索引命名规范

| 类型 | 命名格式 | 示例 |
|-----|---------|------|
| 主键索引 | pk_{表名} | pk_system_user |
| 唯一索引 | uk_{表名}_{字段名} | uk_system_user_username |
| 普通索引 | idx_{表名}_{字段名} | idx_apartment_district_id |

#### 4.1.1 system_user（系统用户表）

```sql
CREATE TABLE `system_user` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` varchar(50) NOT NULL COMMENT '用户名',
  `password` varchar(100) NOT NULL COMMENT '密码',
  `name` varchar(50) NOT NULL COMMENT '姓名',
  `phone` varchar(20) DEFAULT NULL COMMENT '手机号',
  `post_id` bigint DEFAULT NULL COMMENT '岗位ID',

  `update_time` datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_system_user_username` (`username`)
```

## 5. 索引设计

### 5.1 索引汇总表

| 表名 | 索引名 | 字段 | 类型 | 说明 |
|-----|-------|------|-----|------|
| system_user | PRIMARY | id | 主键 | - |
| system_user | uk_system_user_username | username | 唯一 | 用户名唯一索引 |
