## 3. 测试策略与方法

### 3.1 测试策略

| 测试阶段 | 策略 | 说明 |
|---------|------|------|
| 单元测试 | 白盒测试 | 开发人员自行完成，覆盖核心业务逻辑 |

#### 3.2.1 功能测试方法

| 方法 | 适用场景 |

| 判定表法 | 多条件组合 |

#### 3.2.2 界面测试检查点

| 检查项 | 说明 |
|-------|------|
| 布局一致性 | 相同类型页面布局风格一致 |

| 字体规范 | 字体、字号统一 |

## 7. 缺陷管理

### 7.1 缺陷等级定义

| 等级 | 定义 | 示例 |
|-----|------|------|
| 致命 | 系统崩溃、数据丢失 | 页面无法打开、删除数据丢失 |
| 严重 | 功能不可用 | 登录失败、无法保存 |
| 一般 | 功能存在缺陷 | 样式错位、提示信息错误 |
| 轻微 | 体验问题 | 加载速度慢、字体不一致 |

### 7.2 缺陷处理流程

```
缺陷发现
   │
   ▼
缺陷提交
   │
   ▼
开发确认
   │
  不是 ──> 驳回缺陷
   │
  是
   │
   ▼
开发修复
   │
   ▼
测试回归
   │
  通过 ──> 缺陷关闭
   │
  不通过 ──> 重新打开
```
