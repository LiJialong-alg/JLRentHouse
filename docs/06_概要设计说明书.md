## 2. 系统架构设计

### 2.1 总体架构

系统采用B/S（Browser/Server）架构，分为客户端层、服务端层和数据层三层架构。

```
┌─────────────────────────────────────────────────────────────────┐
│                        客户端层 (Client)                         │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────┐      ┌─────────────────────────────┐   │
│  │   Admin 管理端       │      │        App 用户端           │   │
│  │   (Vue 3 + H5)      │      │       (Vue 3 + H5)          │   │
│  └─────────────────────┘      └─────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ HTTP/HTTPS
┌─────────────────────────────────────────────────────────────────┐
│                        服务端层 (Server)                         │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              Spring Boot 应用服务器                      │    │
│  │  ┌───────────┬───────────┬───────────┬───────────────┐  │    │
│  │  │ 用户认证  │ 业务模块  │ 接口服务  │  安全中心    │  │    │
│  │  └───────────┴───────────┴───────────┴───────────────┘  │    │
│  └─────────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              MinIO 对象存储服务器                        │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                         数据层 (Data)                           │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────┐   │
│  │   MySQL     │  │    Redis     │  │       MinIO          │   │
│  │  业务数据    │  │    缓存      │  │     文件存储         │   │
│  └──────────────┘  └──────────────┘  └──────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

## 4. 接口设计

### 4.1 接口规范

#### 4.1.1 RESTful API设计原则

| 方法   | 用途     | 示例                         |
| ------ | -------- | ---------------------------- |
| GET    | 查询资源 | GET /admin/apartment/page    |
| POST   | 创建资源 | POST /admin/apartment/save   |
| PUT    | 更新资源 | PUT /admin/apartment/update  |
| DELETE | 删除资源 | DELETE /admin/apartment/{id} |

#### 4.1.2 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| 字段    | 类型    | 说明   |
| ------- | ------- | ------ |
| code    | Integer | 状态码 |
| message | String  | 消息   |
| data    | Object  | 数据   |

## 5. 数据存储设计

### 5.1 数据库选型

| 数据库    | 用途         | 说明       |
| --------- | ------------ | ---------- |
| MySQL 8.0 | 业务数据存储 | 主数据库   |
| Redis     | 缓存和会话   | Token缓存  |
| MinIO     | 文件存储     | 图片等文件 |

### 5.2 缓存设计

| 缓存内容   | 缓存键         | 过期时间 | 说明         |
| ---------- | -------------- | -------- | ------------ |
| 用户Token  | token:{token}  | 24小时   | JWT Token    |
| 用户信息   | user:{userId}  | 1小时    | 用户基本信息 |
| 省市区数据 | region:{level} | 30天     | 区域数据缓存 |

### 5.3 文件存储设计

| 文件类型 | 存储路径          | 大小限制 |
| -------- | ----------------- | -------- |
| 公寓图片 | /apartment/{id}/  | 10MB     |
| 房间图片 | /room/{id}/       | 10MB     |
| 用户头像 | /avatar/{userId}/ | 2MB      |

## 6. 安全设计

### 6.1 认证机制

- 采用JWT（JSON Web Token）实现无状态身份认证
- Token有效期24小时
- Token过期后需重新登录

### 6.2 授权机制

- 基于角色的访问控制（RBAC）
- 菜单权限 + 按钮权限
- 接口级别的权限验证

### 6.3 安全措施

| 安全措施     | 实现方式             |
| ------------ | -------------------- |
| 密码加密     | BCrypt加密存储       |
| SQL注入防护  | MyBatis-Plus参数绑定 |
| XSS防护      | 输入输出过滤         |
| CSRF防护     | Token验证            |
| 请求限流     | 接口限流             |
| 敏感数据加密 | AES加密存储          |
